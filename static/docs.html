Como usar a API

Todas as chamadas vao para https://connect.dyalog.com.br e levam o token no cabecalho X-Access-Token. Preencha abaixo e os exemplos ficam prontos para copiar (nada do que voce digitar sai desta pagina).

Qual token usar? O token da instancia (painel > instancia > chave no topo) envia por aquela instancia, e nao precisa informar instancia no corpo. O token master enxerga tudo: com ele, informe "instancia": "ID" nas rotas de envio.

Numero: sempre com DDI e DDD, so digitos (ex.: 5567999999999). Para grupo use "chat_jid": "120363...@g.us" no lugar de numero.

Resposta: todas devolvem {"sucesso": true, "mensagem": "...", "dados": {...}}; em erro, {"sucesso": false, "erro": "codigo", "mensagem": "..."}.
